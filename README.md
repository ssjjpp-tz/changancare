# Chang'an Care

Static website for **Chang'an Care** — a medical travel facilitation service connecting international patients with top-tier hospitals in Xi'an, China.

**Live site:** https://changancare.com

## Stack

Single-file static site: `index.html` (HTML + CSS + vanilla JS, no build step, no dependencies).

## Deploy

Hosted on **Cloudflare Pages**:

- Direct upload: Workers & Pages → Create deployment → Upload assets → drop `index.html`
- Or connect this repository for automatic deployments on push

Custom domain `changancare.com` is bound in Pages → Custom domains (DNS + HTTPS managed by Cloudflare).
